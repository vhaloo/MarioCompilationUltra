# Public distribution boundary

The public Git repository and release packages contain the original host
source, licensed emulator/UI/compression/platform source, a licensed font,
original geometric branding, documentation and binaries built from those
sources. Public screenshots show only the ROM-free application menus.

They exclude Nintendo cartridge files, extracted sprites/tiles, level packs,
music/audio captures, private gameplay screenshots, save RAM, snapshots,
commercial game routines reconstructed from disassemblies, ROM patches,
personal ROM paths, research checkouts and original ROM inventories.

The executable requires the user's local cartridge. `tools/audit_public.py`
checks tracked paths, archives, save-state signatures and recognised retail
cartridge headers before packaging. This is a defined content audit, not a
blanket legal certification. The original code and licensed dependencies are
themselves copyrighted and are distributed under their stated permissions.

Original project files are MIT-licensed. **The complete application is
noncommercial** because it includes Snes9x. Preserve the Snes9x notice and all
third-party licences. The release supplies corresponding source, including
the complete pinned SDL source archive and the used emulator/UI/zlib sources.
No sale or paid commercial bundle is authorised by this project's licence.

Compatible game names are descriptive; this project has no Nintendo affiliation.
Users are responsible for their entitlement to use their local game data.
