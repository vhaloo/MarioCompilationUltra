Tourne la couronne ou la lunette pour zoomer. Dans les menus, elle fait défiler ; les boutons tactiles + et - fonctionnent aussi.

0 % : toute la zone chargée. 100 % : caméra originale. Les portes et tuyaux peuvent charger une autre zone.

Dans la plupart des jeux, B fait sauter et Y fait courir ou saisir. Utilise plusieurs doigts pour maintenir direction et action.

Mets en pause avec l’icône pause ou Retour Android. Reprendre conserve la partie. Quitter se trouve au bas de Collection.

Un paquet personnel inclut tes cartouches locales. Les paquets publics nécessitent tes propres fichiers compatibles.

Transfère les cartouches dans CartridgeInbox, puis choisis Vérifier les cartouches transférées ou redémarre l’application. Les fichiers existants sont préservés.

Les commandes physiques et les performances prolongées sur montre restent à tester. Cette édition est expérimentale.

```text
/sdcard/Android/data/com.vhaloo.mariocompilationultra.wear/files/CartridgeInbox/

adb install -r MarioCompilationUltra-0.9.2-Wear-public.apk

```
