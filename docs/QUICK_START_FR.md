# Mario Compilation Ultra — démarrage

Extrais entièrement le dossier téléchargé et ouvre l'application. Elle démarre
en plein écran sans bordure ; la bibliothèque et les menus restent au centre
quand la fenêtre s'étend sur plusieurs écrans.

Dans **Choisir une cartouche…**, sélectionne ton fichier ZIP, SMC ou SFC.
**All-Stars + World** fournit Mario 1, Mario 2 américain, Mario 3, Mario World
et Lost Levels. **Yoshi's Island** demande une cartouche séparée. Le bouton
**Importer un dossier…** permet de sélectionner plusieurs éditions locales.
Les fichiers sont reconnus par leur contenu. Un en-tête de copieur est retiré
en mémoire ; les fichiers originaux restent intacts.

Choisis **Jouer**, puis utilise **Entrée / Start** dans le menu du jeu. Lorsque
le jeu montre une démonstration, une première pression peut ramener au titre.
Une seconde commence la partie. Le menu original garde les choix de personnage
et de nombre de joueurs. Les éditions américaines vérifiées d'All-Stars
naviguent automatiquement vers le jeu choisi dans la bibliothèque.

|---|---|---|
| Bouger | Flèches | Stick gauche / croix |
| Sauter, SNES B | Z | Bas |
| Courir / saisir, SNES Y | A | Gauche |

| Atlas | Ctrl+4 | Clic stick gauche |
| Enregistrer / charger | Maj+F1…F9 / F1…F9 | Page Sauvegardes |

L'**atlas du niveau** montre le terrain chargé pour Mario World. Pour les
autres jeux, il conserve le décor déjà observé pendant tes déplacements.
Les zones hachurées n'ont pas encore été observées. Les ennemis suivent leurs
règles d'apparition d'origine. Les cercles creux de World indiquent des
placements possibles ; les points pleins indiquent des objets actifs.

**Panorama** suit le cadrage du jeu en l'élargissant. **Monde en pixels**, à
1×, garde un pixel de jeu par pixel d'écran. **Cadrage original** conserve la
sortie SNES pour les scènes particulières. Les vues expérimentales n'étendent
pas la physique du jeu.

Les données de l'application sont dans son dossier personnel standard, visible
par les chemins de sauvegarde documentés dans FEATURES. Tes sauvegardes
RetroArch et les ROMs sur ton disque ne sont jamais remplacées.

Le logiciel public ne fournit aucune donnée Nintendo. Sa licence autorise une
distribution non commerciale avec les notices des composants. Les sources
correspondantes sont proposées sur la même page de version.
# Plateformes

Windows x64 est compilé et vérifié localement. Linux x64 dispose de contrôles
automatisés, sans essai de jeu sur un poste Linux physique. Les deux versions
**Mac Intel et Apple Silicon sont expérimentales, non testées sur un Mac
physique**. Elles ne sont pas notarifiées par Apple.
